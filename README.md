# Johnlloyd Bacos | Personal Portfolio

A responsive, no-build portfolio site made with HTML, CSS, and JavaScript.

## Run

Open `index.html` in a browser. No package installation or development server is required.

## Personalize

- Add the supplied portrait as `assets/johnlloyd-bacos.jpg`. Keep the existing photo markup and replace the file only with Johnlloyd's original image.
- Edit the About, Education, skills, projects, and academic-work text directly in `index.html`.
- Replace the `href="#"` values on the Facebook and Instagram links with the real profile URLs.
- Replace each project's placeholder art and text with the actual project screenshot, description, and technology list.
- Styles are in `css/styles.css`; navigation and academic file selection behavior are in `js/main.js`.

Academic Works file selection creates temporary browser-session links only. To keep files with the site, add them to the project folder and update the corresponding section in `index.html`.

The page uses Manrope and DM Mono from Google Fonts when online; local fallback fonts are included.
